# qualWeldChit

Генератор документов: загружаете xlsx с данными сварщиков, выбираете метод
контроля (ВИК / РК / ПВК), получаете zip-архив с заполненными docx-актами.

## Структура проекта

- `client/` — фронтенд (React + Vite)
- `server/` — бэкенд (Node.js + Express)
- `templates/<квалификация>/<способ сварки>/<метод контроля>.docx` — шаблоны
  документов, например `templates/2/РД/ВИК.docx`
- `input_example/` — пример входного xlsx-файла

## Требования

- Node.js 18+ и npm

## Запуск (macOS и Windows одинаково)

Из корня проекта:

```bash
npm run install:all   # установить зависимости клиента и сервера
npm run dev            # запустить сервер (:3001) и клиент (:5173) вместе
```

Открыть в браузере адрес, который выведет Vite (обычно http://localhost:5173).

Запустить отдельно, если нужно:

```bash
npm run dev:server   # только бэкенд
npm run dev:client   # только фронтенд
```

## Формат входного xlsx

Первая строка — заголовки колонок (порядок неважен):

`ФИО | Клеймо | Организация | Квалификация | Способ сварки | Дата сварки | Дата контроля | Номер`

- Из «Квалификация» берётся первая цифра (например, из
  «...2 уровень квалификации...» → `2`).
- Из «Способ сварки» берутся буквы (например, «РД»).

## Добавление нового шаблона

Положить docx-файл по пути `templates/<цифра квалификации>/<способ сварки>/<метод контроля>.docx`,
например `templates/2/РД/РК.docx`. Плейсхолдеры внутри шаблона:
`{{number}}`, `{{i_day}}`, `{{company}}`, `{{fio}}`, `{{w_day}}`, `{{lable}}`.

В шаблоне РК есть ещё `{{den}}`: в каждое место подставляется своё случайное
число от 1,90 до 2,05, и в одном документе все числа отличаются друг от друга
не больше чем на 0,05.

## Один шаблон или несколько

- Если в папке `templates/<квалификация>/<способ сварки>` **несколько** шаблонов
  (например `templates/3/РД`: ВИК, РК, ПВК), то для каждого сварщика создаются
  все акты сразу. Они лежат в архиве в отдельной папке сварщика, например
  `Иванов И.И. РД(3)/`. Выбирать метод контроля не нужно.
- Если шаблон **один** (например `templates/3/ЗН` или `templates/2/РД`),
  программа работает как раньше: один файл по выбранному методу контроля,
  он лежит прямо в корне архива.

Сразу после выбора файла фронт отправляет его на `POST /api/inspect` и
показывает выбор метода контроля, только если он действительно нужен.

Если для какой-то строки xlsx подходящего шаблона нет — генерация
останавливается с ошибкой, ни один файл не создаётся.

## Известные ограничения

- Готовые архивы хранятся в памяти сервера до первого скачивания
  (перезапуск сервера их удаляет).
